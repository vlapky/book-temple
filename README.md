# Храм Книги

Веб-читалка с озвучиванием для русскоязычных читателей, в том числе с СДВГ и дислексией. Спокойное место, чтобы читать или слушать.

Синтез речи — [vosk-tts-web](https://www.npmjs.com/package/vosk-tts-web) (Vosk TTS 0.10, 57 голосов) прямо в браузере, в отдельном Web Worker. Модель (~285 МБ) скачивается один раз по согласию пользователя и хранится в IndexedDB; если отказаться, используется системный голос (Web Speech API).

## Запуск

Нужен Node.js ≥ 22.12 (требование Vite 8), см. `.nvmrc`.

```bash
nvm use
npm install
npm run dev       # http://localhost:5173
npm run build     # сборка в dist/
npm run preview   # проверка сборки с service worker
```

Dev- и preview-сервер отдают заголовки COOP/COEP, нужные многопоточному WASM. На статическом хостинге их добавляет service worker (после первой загрузки страница один раз перезагружается).

## Возможности

- **Текст**: шрифты Literata, PT Serif, Fira Sans, Andika (OFL, с кириллицей, локально) и Fast Serif / Fast Sans ([Fast Font](https://github.com/Born2Root/Fast-Font), MIT) с выделенным началом слов; размер, интерлиньяж, межбуквенный и межсловный интервал, ширина колонки, отступ абзацев, выравнивание.
- **Цвет**: темы дневная, ночная, сепия, кремовая, цифровая (зелёный на чёрном); ползунок контраста, свои цвета фона и текста, индикатор контрастности WCAG.
- **Чтение вслух**: подсветка слова и предложения, автопрокрутка, 57 голосов (женские, мужские), скорость воспроизведения 0,5–4× без изменения высоты, отдельный темп синтеза, выразительность, переход по предложениям, предзагрузка следующих фраз. Числа читаются словами, знаки ударения учитываются.
- **Концентрация**: режим фокусировки, линейка (строка или абзац), разбивка главы на блоки с показом по одному, прогресс главы и книги, RSVP с точкой фиксации взгляда.
- **Книги**: FB2 (и .fb2.zip), EPUB, TXT, Markdown, HTML, вставка текста; библиотека в IndexedDB; сноски с обратными ссылками; поиск по книге.
- **Закладки, выделения, заметки** с точной позицией (предложение/слово); экспорт заметок в Markdown.
- **Доступность**: семантическая вёрстка (landmarks, `doc-noteref`/`doc-endnotes`), ARIA, видимый фокус, работа с клавиатуры, `prefers-reduced-motion`, `forced-colors`.
- **PWA**: офлайн-оболочка, установка, открытие файлов из системы.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` | пауза / продолжить чтение вслух |
| `←` / `→` | предложение назад / вперёд (при чтении вслух) |
| `+` / `-` | скорость чтения вслух |
| `Esc` | закрыть панель, выйти из фокуса или RSVP |
| `F` | режим фокусировки |
| `T` | оглавление |
| `/`, `Ctrl+F` | поиск |
| `S` | оформление и настройки |
| `M` | закладки и заметки |
| `B` | закладка на текущем предложении |
| `H` / `N` | выделить текущее предложение / заметка к нему |
| `G` | линейка: выкл → строка → абзац |
| `R` | RSVP |
| `J` / `K` | следующий / предыдущий блок |
| `[` / `]` | предыдущая / следующая глава |
| `L` | книги |
| `?` | справка |

Клавиши определяются по физическому положению (`KeyboardEvent.code`), поэтому работают и в русской раскладке.

## Устройство

```
src/
  main.ts            связывание модулей, плеер, горячие клавиши, PWA
  reader.ts          отрисовка главы, позиция чтения, подсветка, блоки, выделения
  settings.ts        настройки (localStorage), темы, контраст
  annotations.ts     закладки, выделения, заметки
  storage.ts         IndexedDB (книги) и localStorage
  book/              разбор FB2 / EPUB / TXT / MD / HTML, zip, демокнига
  text/              деление на предложения и слова, нормализация для синтеза
  tts/               контроллер озвучки, движки Vosk (worker) и Web Speech, список голосов
  ui/                панели, диалоги, RSVP, линейка, панель выделения, иконки
pwa/sw.js            шаблон service worker (список файлов подставляется при сборке)
```

Синхронизация подсветки с голосом Vosk: библиотека не отдаёт таймкоды слов, поэтому длительность слов оценивается по числу слогов и паузам на знаках препинания внутри фактического интервала речи (тишина в начале и конце обрезается). Длинные предложения синтезируются частями — так и оценка точнее, и звук начинается быстрее.
